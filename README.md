# プロジェクトレポート: SimpleTimer

## プロジェクト名称

**SimpleTimer**

## プロジェクト概要

ユーザーが指定した終了時刻（デッドライン）に向けて正確なカウントダウンを行い、期限到達を強力に通知するデスクトップ用タイマーです。通常のタイマー機能に加え、ポモドーロ・テクニック（25分作業/5分休憩）の自動サイクル機能や、進捗を視覚化するブロック式バー、システムトレイ常駐機能を備えています。作業用件の記録と完了ログの保存により、個人のタスク管理と集中力維持を支援することを目的としています。

## 主要な技術スタック

* **プログラミング言語**: Python 3
* **GUIフレームワーク**: Tkinter（標準ライブラリ）
* **システムトレイ管理**: pystray
* **画像処理**: Pillow (PIL)
* **非同期処理**: threading（通知音再生およびトレイアイコン制御の分離）
* **主要な組込モジュール**:
* `datetime`: 精密な時刻計算およびスケジューリング
* `re`: 正規表現による多様な時刻入力形式のパース
* `winsound`: Windows標準の通知音制御（複数パターン実装）

## ファイル一覧と解説

### コア・エントリーポイント

* **`timer.py` (SimpleTimerクラス)**
* **UI/UX構築**: `tkinter` を用いた動的なレイアウト制御を担当。ウィンドウの透過率調整、最前面表示、およびアラーム時の全画面フラッシング機能を実装しています。
* **タイマー・ポモドーロ制御**: 指定時刻へのカウントダウンに加え、ポモドーロモード時は作業と休憩のフェーズ管理を自動で行います。
* **進捗可視化**: 20個のブロックで構成されるキャンバスバーにより、残り時間を直感的に表示。クリックで特定の地点に「マイルストーン」を打つ独自の機能を備えています。
* **システムトレイ統合**: ウィンドウを閉じてもトレイに常駐し、アイコン上に残り分数をリアルタイムに描画して通知します。
* **ロギング**: 完了したタスクと目標時刻をテキストファイルに永続化する処理を担当します。



## エントリーポイント

プログラムの開始と動作の流れは以下の通りです。

1. **起動**: `timer.py` が実行されると、`if __name__ == "__main__":` ブロックにより `tk.Tk` インスタンスが生成され、`SimpleTimer` クラスが初期化されます。
2. **バックグラウンド準備**: `pystray` を用いたトレイアイコンが別スレッドで開始され、待機状態になります。
3. **セットアップ**: ユーザーが用件と終了時刻を入力するか、ポモドーロスイッチをONにします。この際、柔軟な入力パース（例: 1430 → 14:30）が行われます。
4. **監視と更新**: タイマー開始後、`root.after` を利用したメインループが1秒未満の精度で残り時間を監視。トレイアイコンとメイン画面の進捗バーを同期して更新します。
5. **アラーム・継続**: 0秒到達時に最前面でアラームが発動。ユーザーが「停止」または「次のフェーズ開始（ポモドーロ時）」を選択するまで、視覚と音による通知が継続します。
