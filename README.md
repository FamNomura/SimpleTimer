# SimpleTimer

Windows向けの軽量なデスクトップ・スケジュール管理＆カウントダウンタイマーアプリです。  
1日の予定をまとめて登録しておき、「予定の〇分前」に準備・出発用のアラームを鳴らしながら、複数の予定を連続して進行管理できます。

## 主な機能

### スケジュール＆事前通知アラーム
* **「予定の〇分前」事前アラーム**  
  予定ごとに「何分前に知らせるか」を個別設定できます（例：`10:00` の予定を `15分前` の `09:45` に通知）。設定画面で新規予定の既定値も指定可能です。
* **複数予定の連続管理＆自動ソート**  
  登録した予定をアラーム発動時刻順に自動ソートし、1つ終わるごとに次の予定へスムーズに移行します。
* **本番時刻での再通知＆スヌーズ**  
  事前アラーム発動時、本来の予定時刻がまだ未来であれば「予定時刻にもう一度鳴らす」ボタンを表示します。通常の「5分スヌーズ」も利用可能です。
* **実行中の途中割り込み（追加・編集・削除）**  
  タイマーを止めずに予定一覧から突発的な予定を追加・編集・削除できます。現在進行中の予定より早い予定を追加した場合は、自動でそちらへ切り替わります。
* **時刻入力の自動整形**  
  `1000` や `930`、全角数字での入力もフォーカスを外すと自動で `10:00` / `09:30` 形式に整形します。

### ルーティン＆ポモドーロ
* **ルーティン（テンプレート）機能**  
  よく使う1日のスケジュールを名前を付けて保存・切り替えできます。次回起動時には最後に選択したテンプレートを自動で読み込みます。
* **ポモドーロタイマー併用**  
  スケジュール管理と同時に作業／休憩サイクル（デフォルト 25分 / 5分）を並走させることができます。

### デスクトップ操作・視認性
* **マウスホイールでリアルタイム透過度変更**  
  タイマー実行中、上部の「現在の予定」エリア上でのホイール操作（または画面内どこでも `Ctrl + ホイール`）で透過度を 5% 刻みで調整できます。完全に見えなくなるのを防ぐため、下限は 35% に制限されています。
* **タスクトレイ常駐＆直接復帰**  
  ウィンドウを閉じるとタスクトレイに常駐し、残り時間とステータスをアイコン上に表示します。
  * トレイアイコンのクリック／ダブルクリックで即座に前面復帰
  * ホバーで予定時刻・事前通知設定・残り時間を表示
  * 右クリックメニューから「次の予定へ進む」「タイマー停止」「設定を開く」を直接操作
* **通知・外観カスタマイズ**  
  Windowsトースト通知、4種類のアラーム音パターン、常に最前面表示、ライト／ダークテーマ切り替えに対応しています。

## 動作環境

* **OS**: Windows 10 / 11（`winsound` および PowerShell による Windows トースト通知を使用しているため Windows 専用です）
* **Python**: Python 3.8 以上推奨（標準ライブラリ `tkinter` を含む環境）
* **外部ライブラリ**:
  * `pystray`
  * `Pillow`

## 基本的な使い方

### 1. 待機画面（スケジュール登録）
1. 予定ごとに **予定時刻**・**事前(分)**・**予定・用件** を入力します。
2. 繰り返し使う予定は「現在の予定を保存」からルーティンとして保存できます。
3. 必要に応じて「ポモドーロ併用」にチェックを入れ、**「スケジュール開始」** をクリックします。

### 2. 実行画面（カウントダウン中）
* ウィンドウは自動的にコンパクト表示になります。
* **透過度の変更**: 上部の「現在の予定」枠内でマウスホイールを回すか、`Ctrl + マウスホイール` で調整できます。
* **予定の途中変更**: 下部の「本日の予定一覧」から **「＋ 予定を追加」**、または未完了の行をダブルクリック（もしくは `✎` ボタン）で編集・削除できます。
* **設定を開く**: 画面上の余白を右クリック、またはタスクトレイの右クリックメニューから開けます。

### 3. アラーム画面
* 時間になるとウィンドウが最前面に表示され、通知音とトースト通知でお知らせします。
* **確認して次の予定へ (Enter)**: 現在の予定を完了にし、次の予定へ進みます。
* **予定時刻にもう一度鳴らす**: 事前通知のあと、本来の予定時刻ちょうどにもう一度アラームを鳴らします。
* **5分スヌーズ（延長）**: 5分後に再通知します。
